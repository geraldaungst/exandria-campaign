**Purpose:** The lists behind the [[Session Hub]]'s reference cards ("Rulings" and "People and places"). Each bullet with a `[[link]]` becomes an entry that opens to that note in the hub. Edit this note to add, remove, or reorder entries. Text after the link is the description. `[[Note#Heading]]` opens just that section. The heading must match the hub's section name exactly.

## Item finder

Each bullet is a button on the hub. `{q}` in the address becomes the item name you typed. An address without `{q}` opens as written, and the name is copied so you can paste it into that site's search box.

- [D&D Beyond magic items](https://www.dndbeyond.com/magic-items?filter-search={q}) · search by name
- [D&D Beyond equipment](https://www.dndbeyond.com/equipment?filter-search={q}) · mundane gear
