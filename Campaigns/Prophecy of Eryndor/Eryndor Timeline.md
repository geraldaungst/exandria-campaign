In-world events of the Prophecy of Eryndor campaign, oldest first. Each line is an inline event that Calendarium shows on the Exandrian Calendar. Add new events with the [[Close Session]] template (after the game) or quick capture (during play); to add one by hand, copy a line and change the date in the bold label and in `data-date` (`year-month-day`, month as a number from 1), `data-category` (an exact Calendarium category name), the event name (bold, and again in `data-name`), and the description inside the tag. Links go after the event's closing tag, never inside it.

Earlier events (before 19 Thunsheer 835) are in Calendarium itself.
